Privacy Policy

Protecting your data is an important part of VELTRIX. On this page, we explain which data is processed and how your privacy is protected.

1. Data Controller

VELTRIX is the project under which this website and its associated features are provided. Information about the data controller and its contact details can be found in the Legal Notice.

2. General Information

VELTRIX aims to operate with as little data processing as possible. The file encryption and local vault features are designed to process data directly in the browser of the respective user.

3. Hosting via GitHub Pages

This website is hosted using GitHub Pages. The provider is GitHub, Inc. or the relevant GitHub entity.

When you access this website, GitHub may process technical information. This may include, in particular:

  • IP address
  • Date and time of access
  • Browser and device information
  • Pages accessed
  • Referrer information

GitHub states that it logs IP addresses of visitors to GitHub Pages websites for security purposes. VELTRIX has no direct control over this processing.

Further information can be found in GitHub's Privacy Statement .

4. File Encryption

VELTRIX's encryption feature processes selected files directly in the browser. Encryption is performed using the browser's Web Crypto API.

According to the current technical setup, selected files are not transmitted to a dedicated VELTRIX server. Processing takes place locally on the user's device.

5. Local Vault and Browser Storage

The local vault uses IndexedDB, a storage area provided by the browser on the respective device.

Stored files are saved in encrypted form. Additional technical information, such as file names, file sizes and creation dates, may also be stored locally.

According to the current technical setup, this information is not transmitted to a VELTRIX server.

If browser data or website storage is deleted, content stored in the local vault may also be lost.

6. Cookies and Analytics

The reviewed VELTRIX files do not set any cookies of their own or integrate analytics or tracking services.

The website also does not use external fonts or embedded analytics scripts in the reviewed files.

7. External Links

This website does not contain any external links.

8. Legal Bases

Where personal data is processed, this is done on the basis of the applicable data protection regulations. The specific legal basis depends on the respective processing activity.

The processing of technical access data by the hosting provider takes place under its own responsibility and privacy rules.

9. Your Rights

Subject to the applicable legal requirements, you have the following rights in particular:

  • Right of access to stored personal data
  • Right to rectification of inaccurate data
  • Right to erasure of personal data
  • Right to restriction of processing
  • Right to object to certain processing activities
  • Right to data portability
  • Right to lodge a complaint with a data protection supervisory authority

To exercise your rights, you can contact the data controller listed in the Legal Notice.

10. Changes to This Privacy Policy

This Privacy Policy may be updated if the website, its features or legal requirements change.

The version currently published on this website shall apply.
