Datenschutzerklärung

Der Schutz deiner Daten ist ein wichtiger Bestandteil von VELTRIX. Auf dieser Seite erklären wir, welche Daten verarbeitet werden und wie deine Privatsphäre geschützt wird.

1. Verantwortliche Stelle

VELTRIX ist das Projekt, unter dem diese Website und die dazugehörigen Funktionen bereitgestellt werden. Die Angaben zur verantwortlichen Stelle und deren Kontaktmöglichkeiten findest du im Impressum.

2. Allgemeine Hinweise

VELTRIX legt Wert auf einen möglichst datensparsamen Betrieb. Die bereitgestellten Funktionen zur Datei-Verschlüsselung und zum lokalen Tresor sind darauf ausgelegt, Daten direkt im Browser des jeweiligen Nutzers zu verarbeiten.

3. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Anbieter ist GitHub, Inc. beziehungsweise die zuständige GitHub-Gesellschaft.

Beim Aufruf der Website können durch GitHub technische Informationen verarbeitet werden. Dazu können insbesondere gehören:

  • IP-Adresse
  • Datum und Uhrzeit des Zugriffs
  • Browser- und Geräteinformationen
  • aufgerufene Seiten
  • Referrer-Informationen

GitHub gibt an, IP-Adressen von Besuchern einer GitHub-Pages-Website aus Sicherheitsgründen zu protokollieren. Auf diese Verarbeitung hat VELTRIX keinen unmittelbaren Einfluss.

Weitere Informationen findest du in der Datenschutzerklärung von GitHub .

4. Datei-Verschlüsselung

Die Verschlüsselungsfunktion von VELTRIX verarbeitet ausgewählte Dateien direkt im Browser. Die Verschlüsselung erfolgt mithilfe der Web-Crypto-API des Browsers.

Nach dem derzeitigen technischen Aufbau werden die ausgewählten Dateien nicht an einen eigenen VELTRIX-Server übertragen. Die Verarbeitung findet lokal auf dem Gerät des Nutzers statt.

5. Lokaler Tresor und Browser-Speicher

Der lokale Tresor verwendet IndexedDB, einen Speicherbereich des Browsers auf dem jeweiligen Gerät.

Die gespeicherten Dateien werden verschlüsselt abgelegt. Zusätzlich können technische Angaben wie Dateiname, Dateigröße und Erstellungszeitpunkt lokal gespeichert werden.

Diese Informationen werden nach dem derzeitigen technischen Aufbau nicht an einen VELTRIX-Server übertragen.

Werden Browserdaten oder Website-Speicher gelöscht, können dadurch auch die im lokalen Tresor gespeicherten Inhalte verloren gehen.

6. Cookies und Analyse

In den geprüften VELTRIX-Dateien werden durch VELTRIX keine eigenen Cookies gesetzt oder Analyse- und Tracking-Dienste eingebunden.

Die Website verwendet außerdem keine externen Schriftarten oder eingebundenen Analyse-Skripte in den geprüften Dateien.

7. Externe Links

Diese Website enthält keine externen Links.

8. Rechtsgrundlagen

Soweit personenbezogene Daten verarbeitet werden, erfolgt dies auf Grundlage der jeweils anwendbaren datenschutzrechtlichen Vorschriften. Die konkrete Rechtsgrundlage richtet sich nach dem jeweiligen Verarbeitungsvorgang.

Die Verarbeitung technischer Zugriffsdaten durch den Hosting-Anbieter erfolgt im Rahmen dessen eigener Verantwortlichkeit und Datenschutzregeln.

9. Deine Rechte

Im Rahmen der gesetzlichen Voraussetzungen hast du insbesondere folgende Rechte:

  • Recht auf Auskunft über gespeicherte personenbezogene Daten
  • Recht auf Berichtigung unrichtiger Daten
  • Recht auf Löschung personenbezogener Daten
  • Recht auf Einschränkung der Verarbeitung
  • Recht auf Widerspruch gegen bestimmte Verarbeitungen
