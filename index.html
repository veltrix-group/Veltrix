PRIVACY BY DESIGN

Your data belongs to you.

VELTRIX is designed around local processing. The current encryption tools process selected file contents directly in your browser.

✓
Local file processing

Selected files are processed in your browser, not uploaded to a VELTRIX server by the encryption tools.

✓
Authenticated encryption

AES-256-GCM helps protect file contents and detect unauthorized changes.

✓
Browser-based technology

VELTRIX uses the Web Crypto API for its encryption functionality.

QUESTIONS & ANSWERS

Good to know.

Some answers to common questions about VELTRIX.

VELTRIX is a local-first workspace focused on file encryption, private storage and a clear digital working environment.
No account is required to use the current VELTRIX workspace.
The current file encryption tools use AES-256-GCM through the browser's Web Crypto API and derive an encryption key from your password.
VELTRIX Pro is currently planned and in development. Features and pricing will be announced when they are ready.
The current browser vault uses IndexedDB on your device. Clearing browser data can remove locally stored vault files, so keep separate backups.
